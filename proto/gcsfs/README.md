# proto/gcsfs

## Overview
Protocol buffer definitions and service schemas for the `gcsfs` sidecar and client communication protocol.

## Subdirectories & Boundaries
- [v1](./v1/README.md): Protocol buffer contracts (v1) for the sidecar `FileSystemService`, covering file inspection, streaming byte-range reads, and atomic streaming writes.
- [v1](./v1/README.md): Protocol buffer contracts (v1) for the sidecar `FileSystemService`, covering file inspection, directory listing, streaming byte-range reads, and atomic streaming writes.
